# Otakar Šimek Apps

## Poctivý software za poctivou cenu.

Oficiální web společnosti Otakar Šimek Apps.

Web představuje aplikace, filozofii značky a poskytuje informace pro uživatele.

---

## Cíle projektu

- představit značku Otakar Šimek Apps,
- prezentovat aplikace Finance Manager a PaintMaster,
- poskytovat podporu uživatelům,
- zveřejňovat zásady ochrany soukromí,
- nabídnout kontaktní informace,
- vytvořit moderní a rychlý web.

---

## Technologie

Flutter Web

---

## Stav projektu

🟢 Produkční web

Web je nasazen prostřednictvím Cloudflare Pages.

Probíhá aktivace vlastní domény **otakarsimek.cz** a přechod DNS správy z WEDOS na Cloudflare.
